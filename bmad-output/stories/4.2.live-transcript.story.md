# 4.2: Live Transcript Display

**Story ID:** 4.2
**Epic:** 4 — Frontend
**Slug:** live-transcript
**Status:** review

> Owned by planning until `ready-for-dev`. Sized to one dev-day (~2-8h). No story points.

## Story

As a **user**,
I want **a running text transcript of both sides of the conversation**,
so that **I can follow along with and review what was said, not just rely on audio**.

## Acceptance Criteria

1. A transcript panel is visible in the UI throughout an active session.
2. After each turn, the user's transcribed text and the AI's reply text (both returned by `POST /api/session/{id}/turn`) are appended to the panel in order.
3. The transcript panel auto-scrolls to show the latest turn.
4. Each entry is visually labeled by speaker (user vs. AI).
5. The transcript clears when a new session starts.

## Tasks / Subtasks

- [ ] Build `frontend/components/transcript.js` rendering a labeled, ordered turn list (AC: #1, #4)
- [ ] Hook transcript updates into the turn-response handling in `frontend/app.js` (AC: #2)
- [ ] Add auto-scroll to the latest entry (AC: #3)
- [ ] Clear transcript state on new session start (AC: #5)

- **Implementation notes:**
  - **Scope deviation (necessary, not accidental):** neither `index.html` nor `styles.css` was in this story's declared Owned Scope, but there was no way to satisfy the ACs without touching both: a `#transcript-panel` container element and its `<script>` tag have to live somewhere in `index.html` (transcript.js can't inject its own `<script>` tag without a hackier dynamic-injection pattern that wasn't used anywhere else in this codebase), and AC#3's "auto-scroll" is meaningless without CSS giving the panel a bounded height + `overflow-y: auto` — otherwise `panel.scrollTop = panel.scrollHeight` is a no-op on an unbounded page. Both edits are additive and don't touch anything 4.1 already owns functionally.
  - `transcript.js` exposes `clear()` and `appendTurn(userText, aiText)`; each entry is a `<p data-speaker="user|ai">` with a bold "You"/"AI" label (AC#4) and CSS color-codes each speaker distinctly.
  - Auto-scroll (AC#3) is a plain `panel.scrollTop = panel.scrollHeight` after appending both entries of a turn.
